# AI Usage Guardian — ИИ-агент контроля использования нейросетей

## Что это
Контроль безопасного использования нейросетей сотрудниками и снижение рисков утечек через ИИ.

## Что делает
- Санитизация промптов перед отправкой в публичные нейросети (замена ПД, телефонов, финансовых данных на `[ДАННЫЕ_СКРЫТЫ]`)
- Мониторинг аномальных объемов данных, уходящих на API публичных нейросетей
- Автоматическая рассылка коротких кейсов по безопасному использованию ИИ
- Генерация Политики использования ИИ под специфику компании

## Эффект
- Предотвращает случайную утечку конфиденциальной информации через ИИ
- Снижает вероятность нарушений 152-ФЗ через ИИ
- Формирует культуру безопасного использования ИИ
- Снижает вероятность инцидентов на 60-70%
