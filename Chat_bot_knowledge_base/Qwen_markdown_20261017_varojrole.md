# IDP Agent — ИИ-агент обработки первичной документации

## Что это
Автоматическое извлечение данных из неструктурированных документов (сканы, фото, PDF счетов, актов, накладных) и передача их в учетные системы.

## Что делает
- Распознает текст (OCR) и понимает структуру документа
- Извлекает ключевые поля: ИНН, номер счета, сумма, дата, наименование товаров
- Сверяет извлеченные данные с контрагентом (интеграция с Due Diligence Agent)
- Формирует готовый к загрузке файл или создает документ в 1С через API

## Эффект
- Сокращение времени обработки одного документа с 10 минут до 30 секунд
- Минимизация ошибок ручного ввода (ошибки в 5-10% случаев при ручном вводе)
- Высвобождение 20-30 часов в неделю для бухгалтерии и отдела закупок

## Цена
- Внедрение: от 50 000 руб. (единоразово)
- Подписка: от 12 000 руб./мес. (включает до 1000 документов)
- Сверх пакета: ~5 руб. за документ

## Срок внедрения
2-3 недели

## Интеграции
- 1С:Предприятие (через API или COM-интерфейс)
- SAP, Microsoft Dynamics
- Документооборот: Directum, DocsVision
