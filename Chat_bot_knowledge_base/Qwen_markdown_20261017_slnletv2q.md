# Модели ценообразования

## Модель 1: SaaS (Облачная) — рекомендуется для МСП

**Как работает:**
- Лицензия: 10 000-15 000 руб./мес. (доступ к платформе, хостинг, поддержка)
- Включен базовый пакет токенов/минут/документов
- Сверх пакета — доплата по факту использования

**Плюсы:**
- Низкий порог входа
- Предсказуемые ежемесячные затраты
- Не нужно покупать серверы

**Для каких продуктов:**
- Sales Intelligence Agent
- IDP Agent
- Lead Qualification Agent
- Knowledge Base Agent

## Модель 2: On-Premise (Локальная) — для компаний с жесткими требованиями к данным

**Как работает:**
- Лицензия: 100 000-180 000 руб. (единоразово)
- Подписка на обновления и поддержку: 10 000-18 000 руб./год
- Клиент сам покупает API-ключи у Yandex/Sber

**Плюсы:**
- Данные не покидают контур клиента
- Полный контроль над системой
- Нет ежемесяных платежей за токены

**Для каких продуктов:**
- Due Diligence Agent
- HR Security Agent
- Security Awareness Agent
- Incident Response Agent
- PD Compliance Agent
- Trade Secret Guardian
- AI Usage Guardian

## Модель 3: Гибрид — "Золотая середина"

**Как работает:**
- Лицензия: 50 000-100 000 руб. (единоразово) — настройка и интеграция
- Подписка: 10 000-15 000 руб./мес. — включает базовый пакет токенов
- Сверх пакета — доплата

**Плюсы:**
- Предсказуемость затрат
- Стабильный recurring revenue для студии
- Возможность резеллинга токенов с наценкой

## Кто платит за токены?

**В модели SaaS:** Базовый пакет включен в подписку, сверх — доплата.
**В модели On-Premise:** Клиент покупает API-ключи у Yandex/Sber напрямую.

## Цены российских LLM (актуально на 2026 год)

**YandexGPT:**
- Входные токены: ~0.6 руб. за 1000 токенов
- Выходные токены: ~1.2 руб. за 1000 токенов
- Средний диалог чат-бота: ~0.5-1 руб.

**GigaChat:**
- Входные токены: ~0.5 руб. за 1000 токенов
- Выходные токены: ~1.0 руб. за 1000 токенов

**Yandex SpeechKit (STT):**
- Аудио файлом: ~1.0 руб./мин
- Аудио в реальном времени: ~1.5 руб./мин

**Преимущества российских моделей:**
- Соответствие 152-ФЗ (данные не уходят за рубеж)
- Стоимость в 3-5 раз ниже, чем OpenAI
- Высокое качество для русского языка
