# HR Security Agent — ИИ-агент проверки персонала

## Что это
Автоматическая проверка кандидатов при найме и периодическая перепроверка действующих сотрудников.

## Что делает
- Проверка дипломов через ФРДО (Федеральный реестр документов об образовании)
- Проверка исполнительных производств через ФССП
- Проверка деловой активности через СПАРК (учредитель/директор в компаниях)
- Проверка на банкротство через Федресурс
- OSINT-анализ открытых источников (с согласия проверяемого)
- Мониторинг аномального поведения сотрудников через анализ IT-логов (Windows Event Logs, логи 1С, веб-CRM)

## Юридический аспект
Все проверки проводятся только с письменного согласия кандидата/сотрудника в соответствии с 152-ФЗ. Проверка судимостей — только через официальную справку об отсутствии судимости через Госуслуги (требование ТК РФ).

## Эффект
- Выявляет поддельные дипломы и документы
- Обнаруживает кандидатов с финансовыми проблемами или признаками фиктивного бизнеса
- Выявляет инсайдеров на ранней стадии
- Снижение вероятности найма неблагонадежных лиц на 60-70%

- IT-логи: Windows Event Logs, логи 1С, веб-CRM
