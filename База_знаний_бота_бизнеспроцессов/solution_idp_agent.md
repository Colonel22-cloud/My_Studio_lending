# Решение: ИИ-агент обработки первичной документации (IDP Agent)

## Назначение
Автоматическое извлечение данных из неструктурированных документов (сканы, фото, PDF счетов, актов, накладных) и передача их в учетные системы.

## Что делает агент
- Распознает текст (OCR) и понимает структуру документа.
- Извлекает ключевые поля: ИНН, номер счета, сумма, дата, наименование товаров.
- Сверяет извлеченные данные с контрагентом через вашего же Агента Due Diligence.
- Формирует готовый к загрузке файл или создает документ в 1С через API.

## Как снижает риск
- Исключает ошибки "человеческого фактора" при ручном вводе.
- Ускоряет документооборот в 5-10 раз.
